# PROJECT: TradePilot – Intelligent Options Trading Command Center

## 1. Project Overview

Build a professional, modern, responsive web application named **TradePilot**.

Tagline: "Trade Smarter. Measure Everything."

TradePilot is a personal options trading platform focused initially on SPX 0DTE (Zero Days to Expiration) options trading.

The application must combine:

1. Options strategy analysis and strategy builder.
2. Paper trading and simulation.
3. Robinhood MCP broker integration.
4. Market data and options chain monitoring.
5. Automated entry and exit rule management.
6. TradingView signal integration.
7. Robinhood trading history synchronization.
8. Automated trading journal.
9. Performance analytics and strategy comparison.
10. Risk management and trading configuration.

Build the application so it can initially run using free-tier services and paper trading without submitting real broker orders.

The architecture must allow future expansion into live trading and additional brokers.

IMPORTANT:
Do not build only a static dashboard or a collection of mockups. Build functional modules, reusable components, database integration, actual CRUD operations, validation, error handling and a working paper trading engine.

Never fabricate live market prices, broker connectivity, option quotes, execution confirmations or trading history.

If an external service is not configured, clearly display DEMO, SIMULATED or NOT CONNECTED status.
